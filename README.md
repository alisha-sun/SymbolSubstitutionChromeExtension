# SymbolSubstitutionChromeExtension

for people tired of copy-pasting math symbols and emojis from google (:

## Controls
- Import, export, add, or remove symbols from the Chrome Extension popup
- Type `:symbol-name:` and press right-arrow to replace it with your symbol
- Partially typed symbol names (e.g., `:symbol-na`) will be interpreted as the first alphabetically matching symbol name

## Status & Limitations
- Currently only supports `contenteditable` HTML elements
- Your command must be typed at the end of the text node
